WaifuStudio — это локальная рабочая среда для производства аниме-изображений и коротких видео. Она объединяет генерацию изображений, референсы персонажей, генерацию видео, редактирование, апскейлинг, сборку в Timeline и управление галереей в одном веб-интерфейсе, где ComfyUI выступает движком вывода.

## Языки

Интерфейс доступен на **английском (по умолчанию)**, **испанском**, **японском**, **упрощённом китайском** и **русском** языках. Для переключения служит кнопка с глобусом в верхней панели. Технические названия моделей, примеры prompt, пользовательский контент и некоторые сообщения об ошибках бэкенда остаются на исходном языке.

Приложение рассчитано на одну GPU NVIDIA и настольную систему Windows. Оно не требует учётной записи, облачного сервиса или телеметрии. Установщик размещает Python, ComfyUI и FFmpeg в переносимом каталоге.

> [!WARNING]
> **Статус и область применения**: это независимый проект, предоставляемый «как есть», без гарантий. Он разрабатывается и тестируется на эталонной конфигурации, приведённой ниже. Другие GPU, операционные системы и сценарии работы могут подойти, но официально не проверены. Возможны недоработки, поэтому храните резервные копии проектов и сгенерированных материалов.

## Установка (Windows)

### Перед началом

- Windows 10/11 (64-бит).
- GPU NVIDIA; на эталонной машине используется RTX 3060 с 12 ГБ.
- Драйвер NVIDIA версии 570 или новее (стек использует CUDA 13).
- Git для Windows, если нужны автоматические обновления. Установка из ZIP работает без Git.
- Достаточный объём свободного места для набора моделей. Установщик показывает размер и запрашивает подтверждение перед загрузкой.
- Короткий локальный путь надёжнее синхронизируемой папки, например `C:\AI\WaifuStudio`.
- Если запущена более старая копия, сначала остановите её командой `stop.bat`.

### Вариант A: клонирование через Git (рекомендуется)

1. Клонируйте репозиторий:

```powershell
git clone https://github.com/gusnion/WaifuStudio.git
cd WaifuStudio
```

2. Установите:

```powershell
install.bat
```

Установщик создаёт изолированную среду Python, ComfyUI, пользовательские узлы, FFmpeg и ярлык. Он также спрашивает, какие модели загрузить. Повторный запуск безопасен: установщик проверяет, что уже существует, и устанавливает только недостающее.

3. Запустите приложение:

```powershell
start.bat
```

Приложение открывается по адресу `http://127.0.0.1:8765` в отдельном окне.

4. Остановите приложение или запустите диагностику:

```powershell
stop.bat
healthcheck.bat
```

Если модели уже есть на диске, а нужны только движок и приложение:

```powershell
install.bat -SkipModels
```

Не используйте `-SkipModels` при первой установке, если рекомендуемые модели ещё нужны.

### Вариант B: ZIP

1. Загрузите ZIP и распакуйте его в новую папку. Не распаковывайте поверх старой установки.
2. Запустите `install.bat` в новой папке.
3. Запустите `start.bat`.
4. Продолжайте работать в этой папке. У ZIP-установок нет метаданных Git, поэтому `update.bat` не может их обновлять.

### Команды

```text
start.bat        запуск приложения и движка
stop.bat         остановка приложения и движка
update.bat       обновление установки Git
healthcheck.bat  проверка путей и служб
start_engine.bat запуск только ComfyUI
stop_engine.bat  остановка только ComfyUI
```

FFmpeg устанавливается по умолчанию. Флаг `-SkipFfmpeg` доступен для минимальных установок, но в этом случае не будут работать экспорт и склейка в Timeline. `install.bat` также создаёт `WAIFUSTUDIO.lnk` со значком приложения; если папка перемещена, запустите `scripts\create_shortcut.ps1` или повторите запуск установщика.

## Обновление

### Установка через Git

`update.bat` останавливает приложение, сохраняет `data/` и `ComfyUI/user/` в `%LOCALAPPDATA%\WaifuStudio\backups\update-<date>`, выполняет `git pull --ff-only`, повторно запускает установщик и снова открывает приложение.

Перед обновлением:

- Завершите или отмените активные задачи ComfyUI.
- Если `git status --short` показывает отслеживаемые изменения, закоммитьте или сохраните их. Обновлятор отказывается их перезаписывать.

Обычное обновление:

```powershell
update.bat
```

Сначала проверка без изменений:

```powershell
update.bat -DryRun
```

Полезные варианты:

```powershell
update.bat -NoStart        # обновление без запуска приложения
update.bat -InstallModels  # также загрузить недостающие модели
```

По умолчанию новые модели не загружаются. Обновление не выполняется, если в репозитории есть отслеживаемые локальные изменения, если текущая ветка не `main` или если в ComfyUI остаются активные задачи. `install.bat -Update` — псевдоним для `update.bat`.

### Установка из ZIP

Для ZIP-установок обновление на месте не предусмотрено. Обновляйте вручную:

1. Остановите приложение командой `stop.bat`.
2. Сделайте резервную копию `data/`, `ComfyUI/user/`, `.env` и `config.local.json`, если они есть. Также скопируйте `ComfyUI/models/`, если не планируется повторная загрузка моделей.
3. Распакуйте новый ZIP в новую папку.
4. Скопируйте `data/`, `ComfyUI/user/` и, если они сохранены, `ComfyUI/models/` из старой папки в новую.
5. Запустите `install.bat` в новой папке.
6. Запустите приложение и проверьте галерею и проекты, прежде чем удалять старую папку.

Обновлятор для Git оставляет резервную копию с отметкой времени. Храните её, пока новая версия не будет проверена.

Текущий значок временный. Исходный файл — `waifystudioicon.ico`; приложение отдаёт `static/favicon.ico`, а README использует `static/waifustudio-icon.png`.

## Добавление моделей для изображений и LoRA

Репозиторий не содержит сторонних чекпоинтов и LoRA. Установщик загружает стартовый набор; дополнительные файлы копируются вручную. Встроенного браузера моделей пока нет.

### Куда помещаются файлы

| Ресурс | Папка | Формат | Примечания |
|---|---|---|---|
| SDXL-чекпоинт | `ComfyUI/models/checkpoints/` | `.safetensors` | Включает CLIP и VAE. Сюда же помещаются SDXL-чекпоинты Illustrious и Pony, а также модели в стиле NoobAI. |
| Anima 2.9B UNET | `ComfyUI/models/diffusion_models/` | `.safetensors` | Требует текстовый энкодер Anima и VAE, перечисленные ниже. |
| Anima LoRA | `ComfyUI/models/loras/anima/` | `.safetensors` | Подпапка не обязательна, но помогает определению семейства. |
| LoRA семейства SDXL | `ComfyUI/models/loras/sdxl/` | `.safetensors` | Используйте только с чекпоинтами SDXL/Illustrious. |
| Текстовый энкодер Anima | `ComfyUI/models/text_encoders/` | `.safetensors` | Ожидаемое имя: `qwen_3_06b_base.safetensors`. |
| Anima VAE | `ComfyUI/models/vae/` | `.safetensors` | Ожидаемое имя: `qwen_image_vae.safetensors`. |

Используйте `.safetensors`. Автоматический сканер регистрирует только файлы `.safetensors`; файлы `.ckpt` и `.pt` не обнаруживаются.

### Загрузка и установка

1. Загрузите модель со страницы её официального источника — обычно это Civitai или Hugging Face.
   - На Civitai выбирайте загрузку **Model** или **LoRA**, а не workflow, превью или данные для обучения.
   - На Hugging Face откройте **Files and versions** и загрузите файл `.safetensors`.
   - Модели с возрастными ограничениями требуют учётной записи и принятия их условий.
2. Скопируйте файл в соответствующую папку из таблицы.
3. Если используется Anima, не переименовывайте обязательные файлы энкодера и VAE.
4. Откройте приложение и нажмите кнопку **Перезагрузить** на вкладке «Изображение» либо вызовите `GET /api/models?scan=1`.
5. Откройте **Выбрать LoRA → Управление библиотекой**, чтобы зарегистрировать LoRA, или позвольте сканеру найти её с помощью `POST /api/loras/scan`.
6. Выберите модель и сделайте небольшое тестовое изображение, прежде чем использовать её в проекте.

Подпапки сканируются рекурсивно. Раскладка LoRA по `loras/anima/...` и `loras/sdxl/...` не обязательна, но полезна, если метаданные файла не определяют его базовую модель.

### Совместимые семейства моделей

| Семейство | Совместимость | Примечания |
|---|---|---|
| **Anima 2.9B** | Да | Основное нативное семейство. Модели с 28 блоками — надёжный вариант. Существуют варианты с 40 блоками, но не каждая LoRA для 28-блочных моделей переносится корректно. |
| **SDXL** | Да | Чекпоинт со своими CLIP и VAE. |
| **Illustrious** | Да | Архитектура SDXL; рассматривается как SDXL-чекпоинт. |
| **Pony** | Да | Архитектура SDXL; соглашения по prompt отличаются. |
| **NoobAI-style SDXL** | Да | Архитектура SDXL; соглашения по prompt отличаются. |
| **SD 1.5 / SD 2.1** | Нет | Не проверено; приложение рассчитано на настройки и загрузчики SDXL по умолчанию. |
| **Flux, Qwen-Image и другие архитектуры** | Нет | Вкладка «Изображение» рассчитана на Anima и SDXL. Qwen-Image относится к вкладке «Редактор», а не к этой. |

### Совместимые LoRA

- **Anima LoRA** — используется с UNET Anima.
- **SDXL/Illustrious/Pony LoRA** — используется с чекпоинтом SDXL.
- Не смешивайте семейства. LoRA, обученная для Anima, не будет корректно работать на SDXL, и наоборот.
- LoRA для H3 и Wan относятся к видеосценариям, а не к вкладке «Изображение».
- Приложение пытается прочитать триггер из метаданных LoRA. Если его нет, укажите триггер вручную в библиотеке.
- Начните с веса около `0.6–0.8` для стилевых LoRA и `0.8–1.0` для LoRA персонажей. Далее корректируйте по результату.

### Что нельзя добавить с этого экрана

- ControlNet, IP-Adapter, textual inversion и embeddings не выводятся на вкладке «Изображение».
- Отдельного селектора VAE нет: Anima использует фиксированную пару «энкодер/VAE», а чекпоинты SDXL содержат собственные.
- Файлы Upscaler образуют отдельный фиксированный каталог. Копирование нового `.pth` в `upscale_models` не добавляет его в выпадающий список Upscaler.
- Видеомодели и пресеты H3 не устанавливаются копированием файлов в `checkpoints`.

Перед публикацией сгенерированных работ проверьте лицензию модели. Модели Anima некоммерческие; у моделей SDXL и Civitai собственные условия.

## Эталонная конфигурация

Это оборудование и программное обеспечение, использованные для разработки и проверки. Они не являются минимальными требованиями.

| Компонент | Эталон |
|---|---|
| GPU | NVIDIA GeForce RTX 3060, 12 ГБ |
| CPU | AMD Ryzen 7 5700X, 8 ядер |
| ОЗУ | 32 ГБ DDR4 |
| ОС | Windows 10 (64-бит) |
| Движок | ComfyUI v0.37.4 |
| Python | CPython 3.12.12, изолированный |
| Инференс | PyTorch 2.11.0 + CUDA 13.0 |

Сценарии оптимизированы под 12 ГБ и одновременное выполнение одной задачи. Опциональный помощник Qwen3.5-9B работает на CPU и не отнимает VRAM у ComfyUI.

Windows — поддерживаемый путь установки. Ядро — это стандартные FastAPI, ComfyUI и чистый JavaScript; режим сервера/LAN для Linux запланирован, но пока недоступен.

## Текущие ограничения

- Одна GPU, очередь FIFO. Длительные задачи блокируют другие вкладки до своего завершения.
- H3 создаёт короткие сегменты: 15 секунд за генерацию, с цепочкой результатов там, где это поддерживается.
- Нативный апскейлер видео обрабатывает один пакет и отклоняет видео длиннее 300 кадров. Для длинных видео требуется внешний инструмент.
- Timeline намеренно ограничен: пока нет курсора воспроизведения, маркеров обрезки, drag-and-drop и редактирования волновой формы.
- В этой версии нет lip-sync и автоматической озвучки.
- Облачный вывод, аренда удалённых GPU и магазин моделей пока не интегрированы.
- Встроенное руководство перерабатывается; источником истины о доступных функциях считайте README и фактический интерфейс.

## План развития

Перечисленные ниже пункты запланированы или находятся на рассмотрении. Это не обещания и не даты; они недоступны, если не указано иное.

### Ближайшие планы

- **Пресеты моделей по объёму VRAM** и проверенный менеджер моделей, чтобы установки не рассчитывали на карту с 12 ГБ.
- **Режим Linux Studio**: headless-сервер для локальной сети, отдельный от однопользовательского приложения для Windows.
- **Поддержка удалённых ComfyUI/GPU** с постоянными томами моделей, чтобы длительные задачи не зависели от локальной GPU.
- **Локальные инструменты для агентов**: CLI, skill и режим DSH, которые могут управлять приложением через API.
- **Очередь сцен Timeline** и средство разбиения сценария на сцены с возобновляемыми задачами.

### На рассмотрении

- **Озвучка Chatterbox** для испанской речи, с опциональным lip-sync в качестве отдельного шага.
- **Интеграция Video2X** для апскейлинга длинных видео — как внешний инструмент, а не часть ComfyUI.
- **Профили workflow Wan 2.2**, включая банк workflow сообщества, автором которого указан Artelive.
- **Браузер и загрузчик моделей Civitai** с учётом ограничений API, лицензирования и правил возрастного контента.
- **LTX 2.5**: рассматривается, но в текущем виде непрактичен на GPU с 12 ГБ.
- **Улучшения Timeline как NLE**: курсор воспроизведения, обрезка, drag-and-drop и волновые формы.
