# Imagen

- Modelos oficiales: Anima, Animagine XL 4.0 Opt, RealVisXL V5 y Juggernaut XL Ragnarok.
- El perfil del modelo decide placeholder, preprompt, defaults y visibilidad de zonas.
- Un modelo sin subrama debe aparecer como `Sin clasificar`, nunca sin badge.
- Las LoRAs se filtran por subrama; usa `Ver todas` solo para compatibilidad no verificada.
- Genera desde `POST /api/generate` o desde la pestaña Imagen; revisa el job en `/api/jobs/{id}`.
